Read `4-SYSTEM/Skills/cscd-root-text-intake/SKILL.md` in full, then execute it on the file(s) or input the user specifies.

Skill purpose: Bring a Pāli root-text volume from VRI's CSCD XML into `1-SOURCES/Text/` with block IDs (printed paragraph number = ID), verified word for word against the XML and line for line against tipitaka.app. Handles sutta-`<div>` volumes (Dīgha), suttas inside vagga `<div>`s (Majjhima) and saṃyutta `<div>`s with vagga and sutta headings, printed paragraph ranges and gaps (Saṃyutta), and a tree mode that reads heading levels from the XML's own nesting (Aṅguttara); anything else stops the run. A multi-volume work (DN, MN, SN, AN) is joined into one file per nikāya with `merge_volumes.py`, each volume a `##` chapter.
